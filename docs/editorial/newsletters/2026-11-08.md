# The Security Diff — 2026\-11\-08

Seven reports from November 2–8: cPGuard, kaniko, NIKKE, Rails, a malicious Ruby gem, Linux TCP, and GeoNode\.

## Lead story

### [cPGuard update\-channel breach exposes root\-level server secrets](https://opsshield.com/notice/security-incident-disclosure-servermanage.html)

Supply Chain

OPSSHIELD says attackers used its cPGuard update channel to send a malicious update on November 2\. Its later disclosure describes roughly 70 minutes of malicious distribution and exposure of root\-level secrets, superseding the vendor’s earlier account\.

### [kaniko lookalike registry hosts can receive a build’s Azure access token](https://github.com/chainguard-forks/kaniko/security/advisories/GHSA-5q7h-w9jf-cx97)

Vulnerabilities

The Chainguard kaniko fork’s advisory describes Azure access\-token exposure when untrusted Dockerfiles or build arguments reference lookalike registry hosts and an Azure identity is available\. Its bundled credential helper can send a token to an attacker\-controlled registry\.

### [NIKKE PC launcher compromise exposes a trusted CDN delivery path](https://gist.github.com/MotherSphere/d6c049a09ba8ac3085c51ee9df24a4e5)

Supply Chain

MotherSphere’s NIKKE investigation describes tampered scripts on Level Infinite’s CDN loading a remote\-control agent\. Follow\-up reporting describes credential\-stealing capabilities and warns that updated launcher cleanup can erase evidence of an earlier infection\.

### [Rails Active Storage uploads can expose server files through ImageMagick](https://github.com/rails/rails/security/advisories/GHSA-f3w6-w445-fwh9)

Vulnerabilities

Rails’ November 4 advisory describes arbitrary file writes during attachment analysis when Active Storage uses ImageMagick, accepts untrusted uploads, and lacks a restrictive coder policy\. Disk\-backed storage can also expose files readable by the app\.

### [Malicious strutil\-core gem steals secrets and plants AI tool hooks](https://socket.dev/blog/shai-hulud-descendant-malicious-ruby-gem)

Supply Chain

Socket’s November 6 analysis links strutil\-core 1\.0\.1, published November 1, to an install\-time credential stealer and AI tool persistence\. It was a standalone malicious gem; victims and successful downstream infections remain unconfirmed\.

### [Linux TCP flaw puts exposed hosts on the kernel patch list](https://github.com/CVEProject/cvelistV5/blob/main/cves/2026/98xxx/CVE-2026-98432.json)

Vulnerabilities

CVE\-2026\-98432 affects Linux IPv4 TCP connection handling\. Aikido reports a demonstrated remote\-root exploit against an MPTCP listener; that condition should guide urgent exposure checks without being treated as the full boundary of the flaw\.

### [GeoNode vector\-upload layer names can trigger server\-side command injection](https://github.com/GeoNode/geonode/security/advisories/GHSA-9fpx-fr6j-2vh6)

Vulnerabilities

GeoNode’s maintainer reports command execution through crafted vector\-upload layer names\. Its advisory lists versions through 5\.0\.1 as affected\. GitHub’s reviewed database lists 5\.1\.0 as fixed, while the maintainer’s patched\-version field remains unset\.
