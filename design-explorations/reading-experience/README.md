# Reading experience selection

Selected direction: a quiet technical essay with evidence available without losing the reading position.

The integrated comparison uses identical publication tokens with a compact blackletter reader nameplate, a wider title measure, 68-character prose, contextual figures, native Markdown footnotes, and a deliberate close. The essay exposes a generated contents disclosure because it has six meaningful sections. The three-section historical brief omits it and starts with a compact supported-action summary.

The reader texture retains the shared paper grain. Continuous prose and unboxed sections provide the quieter reading surface; no second texture asset or opacity override is introduced. Figures may widen to 880px, while prose remains constrained. Native footnote anchors supply keyboard and no-JavaScript return navigation.

`capture.mjs` records both samples and the CVE reference page at the required widths and themes. Output is written to `/private/tmp/tsd-reading-experience/after/` with `manifest.json`.

The original technical essay is explicitly credited as an editorial prototype and labeled an unreviewed fixture. It is not attributed to the named author in the edition data. The historical brief distinguishes verified vendor and government context from fixture fields that still lack claim-level provenance.
